# 📖 About This Repository

This repository contains a **15-Day SQL Mastery Bootcamp** created for
learners who want to transition into **Data Engineering** using
**PostgreSQL**.

The course is designed for:

-   Automation Engineers
-   Software Engineers
-   QA Engineers
-   Python Developers
-   Data Analysts
-   Anyone preparing for Data Engineering interviews

No prior SQL knowledge is required.

------------------------------------------------------------------------

# 🎯 Learning Goal

By the end of this bootcamp, you should be able to:

-   Write professional SQL queries
-   Work with PostgreSQL confidently
-   Analyze retail business data
-   Build analytical reports
-   Solve SQL interview questions
-   Think like a Data Engineer
-   Prepare datasets for ETL and BI reporting

# 📚 Course Roadmap

  Day   Topics
  ----- -------------------------------------------------------------
  01    SQL Fundamentals, PostgreSQL, SELECT, FROM, ORDER BY, LIMIT
  02    WHERE, Operators, AND, OR, LIKE, BETWEEN, IN, NULL
  03    DISTINCT, Aliases, String, Numeric & Date Functions
  04    Aggregate Functions, GROUP BY, HAVING
  05    INNER, LEFT, RIGHT, FULL, CROSS & SELF JOIN
  06    Multi-table Joins & Business Reporting
  07    Subqueries, EXISTS, IN, ANY, ALL
  08    CTEs & Recursive CTEs
  09    Window Functions, ROW_NUMBER, RANK, DENSE_RANK
  10    LEAD, LAG, Running Totals & Moving Averages
  11    CASE, COALESCE, NULLIF, CAST, Advanced Functions
  12    INSERT, UPDATE, DELETE, Transactions & Views
  13    Constraints, Indexes, EXPLAIN & Query Optimization
  14    Retail Analytics & Executive Reporting
  15    Mock Interview, Capstone Project & SQL Assessment
